# CheckMemo

블랙·그레이 테마의 Windows 체크리스트와 메모장입니다.

[최신 설치 파일 다운로드](https://github.com/contentriumkorea/checkmemo/releases/latest)

- 프로젝트별 전체 메모장 목록, 제목·할 일·자유 메모 전체 검색 (Ctrl+K)
- 자동 백업과 이전 시점 복원, 수동 기록, 삭제·불러오기·복원 전 백업
- 항상 위 고정, 전체 목록 미니모드, 탭을 별도 창으로 꺼내기
- 여러 메모장 탭, 체크리스트, 자유 메모, 자동 저장
- 무료 메모장 1개 · 제공받은 라이선스 키로 활성화하면 여러 탭 사용
- 전용 `.checkmemo` 백업과 기존 JSON 백업 드래그앤드롭 복원
- 전용 백업 아이콘 · 일반 JSON 파일의 연결과 아이콘은 변경하지 않음
- 앱의 **업데이트** 버튼으로 최신 버전 확인, 다운로드, 재시작 설치

상단 **창 진하기** 슬라이더로 투명도를 조절하세요. 40~100% 범위에서 낮출수록 뒤쪽 화면이 비칩니다. **복원**을 누르면 100%가 되고, 재실행해도 설정이 유지됩니다. 무료 사용자도 사용할 수 있습니다.

창 가장자리나 모서리를 끌어 크기를 조절하세요(최소 360×320). 마지막 크기·위치·최대화 상태를 기억하며, 작은 창에서도 버튼이 너비에 맞춰 배치됩니다.

상단 **설정**에서 **윈도우 시작 시 자동 실행**을 켜고 끌 수 있습니다. 새 설치는 기본 꺼짐이고 무료 버전에서도 사용할 수 있습니다. 기존에 등록한 CheckMemo 시작프로그램 바로가기도 스위치를 변경할 때 연결되며, 작업 관리자에서 끈 상태를 반영합니다.

왼쪽 **프로젝트 +**로 프로젝트를 만들고 메모장 위 **프로젝트** 선택에서 이동하세요. 작은 창에서는 **목록**으로 전체 메모장을 볼 수 있습니다. 프로젝트 삭제 시 메모는 미분류에 남습니다.

**전체 메모 검색(Ctrl+K)**에서 검색 결과를 누르면 해당 메모로 이동합니다. **별도 창**으로 분리한 메모장은 그 창에서 편집하고, 창을 닫으면 메인 창으로 돌아옵니다. **미니모드**에서 메모지별 전체 체크리스트와 자유 메모를 한 번에 보고 체크하세요. 긴 내용은 줄바꿈하며 긴 목록은 스크롤합니다. 아래에서 메모지를 선택하고 새 할 일을 입력한 뒤 Enter 또는 **＋**로 추가하세요. **메모지 ＋**는 새 묶음을 만듭니다. 창 높이와 너비를 조절하고 **항상 위**로 고정할 수 있습니다. 미니모드의 **↗**는 일반 창으로 돌아오는 버튼입니다.

**자동 백업 · 이전 상태 복구**에서 기록을 선택해 전체 메모장과 프로젝트를 복원하세요. 복원 전 현재 상태도 보관합니다. 내용 변경 시 최대 5분 간격으로 이전 상태를 보관하며 최근 30개·총 100MB 한도로 관리합니다(최신 1개 유지). **현재 상태 지금 백업**으로 수동 기록을 남길 수 있습니다. 자동 백업은 같은 컴퓨터에 보관되므로 다른 컴퓨터로 옮기려면 **백업 저장**을 사용하세요.

## 처음 사용하기

1. Releases에서 `CheckMemo-1.1.1-Windows-Setup.exe`를 받아 실행합니다.
2. 바탕화면의 앱 아이콘을 열고 **메모지 추가**를 누릅니다.
3. 할 일을 입력하고 Enter를 누르세요. 완료한 항목은 체크합니다.
4. **백업 저장**을 누르면 모든 탭을 전용 백업 파일로 보관할 수 있습니다.

기존 메모는 이전 앱에서 JSON으로 백업한 후 새 앱에 끌어 놓으면 됩니다. 내용이 있는 메모장을 교체할 때는 확인 창이 표시됩니다. 여러 탭을 담은 백업은 라이선스 활성화 후 사용할 수 있습니다.

라이선스는 한 번 활성화하면 재실행과 업데이트 후에도 유지됩니다. 백업에는 활성화 키가 포함되지 않습니다. 키는 별도로 제공받아 사용하세요.
